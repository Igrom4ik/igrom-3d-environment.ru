# План рефакторинга: Этап 1 — Данные и структура

Я приступаю к реализации первого этапа аудита, направленного на унификацию работы с данными и улучшение структуры проекта.

## 1. 📦 Бэкап
- Создание резервной копии директории `src` в `src_backup` для безопасности перед миграцией.

## 2. 🏗️ Стандартизация структуры и Миграция
- **Проверка и миграция контента**:
  - Создание скрипта `scripts/migrate-content.js`.
  - Скрипт проверит `src/content/albums` и перенесет любые файлы вида `slug.mdoc` в `slug/index.mdoc`.
  - Обновление конфигурации Keystatic (`keystatic.config.tsx`), чтобы она соответствовала паттерну `src/content/albums/*/index.mdoc`.

## 3. 🛡️ Валидация и Типизация (Zod)
- Создание `src/core/validation/schemas.ts`:
  - Определение схем Zod для `Project`, `Album`, `Post`.
  - Генерация TypeScript типов из схем (`z.infer`).
- Это станет единственным источником истины для типов контента.

## 4. 🧠 ContentService (Единая точка доступа)
- Создание `src/core/content/ContentService.ts`:
  - Реализация `KeystaticReaderAdapter` для чтения через Keystatic.
  - Реализация `FsReaderAdapter` для прямого чтения (fallback).
  - Единый публичный API: `getAlbum(slug)`, `getAllAlbums()`, `getPost(slug)`.
  - Встроенная валидация данных через Zod схемы при чтении.

## 5. 🔌 Рефакторинг API и Утилит
- **API Endpoints**:
  - Переписывание `src/app/api/portfolio/get/route.local.ts` на использование `ContentService`.
  - Переписывание `src/app/api/portfolio/save/route.local.ts` с валидацией Zod.
  - Внедрение стандартизированных ответов ошибок.
- **Удаление дубликатов**:
  - Замена прямого использования `src/utils/reader.ts` и `src/utils/utils.ts` (в части чтения контента) на `ContentService`.

## 6. 🚀 Оптимизация (Quick Wins)
- **Layout Script**: Вынос скрипта инициализации темы из `layout.tsx` в отдельный файл/компонент.
- **Images**: Замена тегов `<img>` на `next/image` в ключевых местах (где это легко применимо в рамках этого этапа).

Я готов приступить к выполнению. Сначала будет создан бэкап, затем выполнена миграция структуры, и после этого — внедрение `ContentService`.
